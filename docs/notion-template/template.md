## Template page

The template page "📡 SIMerald · SIM / eSIM Console (Template v1)" starts with a usage guide, followed by "📊 Renewals" (the cards sorted by next renewal date) and "💰 Spending" (counters of rows to fix and spending charts). The three databases live in the sub-page "Source databases (do not delete)".

> ### How to Use
> - **What this is**: The official SIMerald Notion template v1. Use it standalone as a SIM/eSIM renewal tracker, or pair it with SIMerald to publish a public card wall ([Setup Tutorial](https://github.com/BurningSky0306/simerald/blob/main/docs/notion-setup.md)).
> - **First steps**: Rows marked with 🧪 are fictional samples. Check them to see how things work, then delete all sample cards, records, and payment accounts.
> - **Daily use**: Check "📊 Renewals"; whenever "⚠️ Data Check" shows a message, fix what it says.
> - **New card**: Create a row in "SIM Cards" and fill in identity info (name as "Carrier · last 4 digits", number with +country-code, country, card type, device), keep-alive actions, renewal cycle/price/currency, and "Default Payment Account". Then add an "Initial purchase" row in that card's "Expense Records" (Date = day you got the card) with "Extends To" and "Payment Account". Put notes, guides, and KYC info in the card page body.
> - **Renewal / keep-alive**: Just add one "Renewal" record in "Expense Records" with "Extends To" and "Payment Account"—the card's "Valid Until", "Next Renewal", and "Status" update automatically without editing the card.
> - **Other spending**: Add a record in "Expense Records" of type "Extra top-up" or "Other fee" and leave "Extends To" empty. Spending carrier balance isn't a new expense; topping it up is, using the "Payment Account" that actually paid.
> - **Special renewal day**: If you should renew before the expiry day (renewal window or promo deadline), set "Next Renewal Override" (a date or range), then clear it after renewing.
> - **Cancelling**: Move linked services away first, then fill "Cancelled On" ("Status" becomes Cancelled automatically) and note the reason in the card page body—don't delete the card.
> - **Countries & currencies**: New countries must follow "flag emoji + space + name"; "⚠️ Data Check" only checks calling codes and exchange-rate ranges for built-in countries/currencies and silently skips others.
> - **Do not rename columns**: SIMerald and formulas look up columns by name (see the tutorial's custom mapping section if you must rename them).

### SIM Cards · Valid Until

```text
lets(
  /* Only records with both "Extends To" and "Date" filled in */
  valid, prop("Expense Records").filter(!empty(current.prop("Extends To")) and !empty(current.prop("Date"))),
  /* Date of the latest transaction */
  latestDay, valid.map(timestamp(dateStart(current.prop("Date")))).sort().last(),
  sameDay, valid.filter(timestamp(dateStart(current.prop("Date"))) == latestDay),
  /* If several records share that date, take the latest "Extends To" */
  latestExtends, sameDay.map(timestamp(dateStart(current.prop("Extends To")))).sort().last(),
  if(empty(valid), parseDate(""),
    sameDay.find(timestamp(dateStart(current.prop("Extends To"))) == latestExtends).prop("Extends To"))
)
```

### SIM Cards · Status

```text
lets(
  expires, prop("Valid Until"),
  /* Cancelled date set = cancelled; past "Valid Until" = expired; otherwise active. and/or do not short-circuit, so date checks use nested if */
  if(!empty(prop("Cancelled On")), "Cancelled",
    if(empty(expires), "Active",
      if(dateBetween(today(), expires, "days") >= 1, "Expired", "Active")))
)
```

### SIM Cards · Next Renewal

```text
lets(
  expires, prop("Valid Until"),
  /* Empty only when cancelled; expired cards still show the date they should have been renewed */
  if(prop("Status") == "Cancelled" or empty(expires), parseDate(""),
    /* Use the manual override when set, otherwise "Valid Until" */
    if(!empty(prop("Next Renewal Override")), prop("Next Renewal Override"), expires))
)
```

### SIM Cards · Urgency

```text
lets(
  status, prop("Status"),
  override, prop("Next Renewal Override"),
  /* Target renewal date: the manual override when set, otherwise "Valid Until" */
  target, if(!empty(override), override, prop("Valid Until")),
  startDay, dateStart(target),
  endDay, dateEnd(target),
  /* Mutually exclusive tiers, evaluated in order */
  ifs(
    status == "Cancelled", "⑨ Number cancelled",
    empty(target), "⑧ No renewal date",
    status == "Expired" or dateBetween(today(), endDay, "days") >= 1, "① Overdue",
    dateBetween(endDay, startDay, "days") > 0 and dateBetween(today(), startDay, "days") >= 0,
      "⓪ Renewal window open (" + format(dateBetween(endDay, today(), "days")) + " days left)",
    dateBetween(startDay, today(), "days") <= 3, "② Within 3 days",
    dateBetween(startDay, today(), "days") <= 7, "③ Within 7 days",
    dateBetween(startDay, today(), "days") <= 15, "④ Within 15 days",
    dateBetween(startDay, today(), "days") <= 30, "⑤ Within 30 days",
    dateBetween(startDay, today(), "days") <= 60, "⑥ Within 60 days",
    "⑦ More than 60 days"
  )
)
```

### SIM Cards · ⚠️ Data Check

```text
lets(
  status, prop("Status"),
  inactive, status == "Expired" or status == "Cancelled",
  expires, prop("Valid Until"),
  override, prop("Next Renewal Override"),
  balanceDay, prop("Balance Checked"),
  actions, prop("Keep-alive Actions"),
  /* Balance-based keep-alive: "Regular use" or "Balance change" is selected. Update this line if you rename those options */
  needsBalance, actions.includes("Regular use (incl. SMS)") or actions.includes("Balance change (e.g. roaming SMS)"),
  number, replaceAll(format(prop("Number")), " ", ""),
  country, format(prop("Country")),
  kind, format(prop("Card Type")),
  /* Record dates are compared as timestamps; records without a date are filtered out first */
  dated, prop("Expense Records").filter(!empty(current.prop("Date"))),
  purchases, prop("Expense Records").filter(format(current.prop("Type")) == "Initial purchase").length(),
  purchaseDay, dated.filter(format(current.prop("Type")) == "Initial purchase").map(timestamp(dateStart(current.prop("Date")))).sort().first(),
  earliestDay, dated.map(timestamp(dateStart(current.prop("Date")))).sort().first(),
  lastRenewalDay, dated.filter(!empty(current.prop("Extends To"))).map(timestamp(dateStart(current.prop("Date")))).sort().last(),
  missing, [
    if(empty(prop("Country")), "Country", ""),
    if(empty(prop("Card Type")), "Card Type", ""),
    /* Virtual numbers live in an app and need no device */
    if(kind != "Virtual Number (App only)" and empty(prop("Device")), "Device", ""),
    if(empty(actions), "Keep-alive Actions", ""),
    if(empty(prop("Renewal Cycle")), "Renewal Cycle", "")
  ].filter(current != "").join(", "),
  /* Calling code of the country; countries not listed here are skipped */
  callingCode, ifs(test(country, "China$"), "+86", test(country, "Hong Kong$"), "+852", test(country, "Macao$"), "+853", test(country, "Taiwan$"), "+886", test(country, "Japan$"), "+81", test(country, "South Korea$"), "+82", test(country, "Singapore$"), "+65", test(country, "Malaysia$"), "+60", test(country, "Thailand$"), "+66", test(country, "Philippines$"), "+63", test(country, "Indonesia$"), "+62", test(country, "Vietnam$"), "+84", test(country, "Sri Lanka$"), "+94", test(country, "UAE$"), "+971", test(country, "Turkey$"), "+90", test(country, "United Kingdom$"), "+44", test(country, "Germany$"), "+49", test(country, "France$"), "+33", test(country, "Netherlands$"), "+31", test(country, "Spain$"), "+34", test(country, "Italy$"), "+39", test(country, "Poland$"), "+48", test(country, "Estonia$"), "+372", test(country, "Switzerland$"), "+41", test(country, "United States$"), "+1", test(country, "Canada$"), "+1", test(country, "Mexico$"), "+52", test(country, "Brazil$"), "+55", test(country, "Australia$"), "+61", test(country, "New Zealand$"), "+64", ""),
  /* Note: Notion and/or do not short-circuit, so date checks use nested if to avoid empty dates */
  [
    if(empty(number), "Number is missing",
      if(!test(number, "^[+][0-9]+$"), "Number should be in +country-code format (digits only)",
        if(!prop("Card Name").contains(number.substring(number.length() - 4)), "Card name does not contain the last 4 digits", ""))),
    if(empty(number) or callingCode == "", "",
      if(number.substring(0, callingCode.length()) != callingCode, "Number does not match the country (should start with " + callingCode + ")", "")),
    if(!inactive and missing != "", "Missing required fields: " + missing, ""),
    if(status == "Expired", "Expired: add a renewal record if you renewed, otherwise fill in the cancelled date", ""),
    /* A dead number may be reassigned, putting linked accounts at risk */
    if(inactive and !empty(prop("Linked Services")), "Number is no longer active but still linked to: " + format(prop("Linked Services")), ""),
    if(!inactive and empty(expires), "No expense record has \"Extends To\" (the initial purchase needs it too)", ""),
    if(purchases != 1, "There should be exactly 1 initial purchase record (currently " + format(purchases) + ")", ""),
    if(empty(purchaseDay) or empty(earliestDay), "",
      if(earliestDay < purchaseDay, "A record is dated before the initial purchase; check its date or type", "")),
    if(empty(override) or empty(expires), "",
      if(dateBetween(dateEnd(override), expires, "days") > 0, "The override renewal date is after \"Valid Until\"", "")),
    if(empty(override) or empty(lastRenewalDay), "",
      if(timestamp(dateStart(override)) < lastRenewalDay, "The override renewal date is older than the latest renewal; clear or update it", "")),
    if(!inactive and prop("Renewal Price") > 0 and empty(prop("Default Payment Account")), "Renewal costs money but no default payment account is set", ""),
    if((format(prop("Renewal Price")) == "") != empty(prop("Renewal Currency")), "Only one of renewal price and renewal currency is filled in", ""),
    /* Balance: 0 is a valid value, so format() is used to detect an empty field */
    if(inactive or !needsBalance, "", if(format(prop("Balance")) == "", "Kept alive by balance but the balance is missing",
      if(prop("Balance") <= 0, "Balance is 0, so it cannot keep the number alive", ""))),
    if(inactive or !needsBalance, "",
      if(empty(balanceDay), "Kept alive by balance but the balance date is missing",
        if(dateBetween(today(), dateStart(balanceDay), "days") > 90, "Balance not checked for over 90 days", "")))
  ].filter(current != "").join("; ")
)
```

### Expense Records · ⚠️ Data Check

```text
lets(
  amountText, format(prop("Amount")),
  day, prop("Date"),
  currency, format(prop("Currency")),
  kind, format(prop("Type")),
  rate, prop("Rate to CNY"),
  extendsTo, prop("Extends To"),
  hasCard, !empty(prop("SIM Card")),
  /* Read the linked card via map so a missing card yields empty values instead of an error */
  cardDigits, replaceAll(prop("SIM Card").map(format(current.prop("Number"))).join(""), "[^0-9]", ""),
  cycleDays, toNumber(replaceAll(prop("SIM Card").map(format(current.prop("Renewal Cycle"))).join(""), "[^0-9]", "")),
  /* Plausible "1 unit = ? CNY" ranges; currencies not listed here are skipped */
  range, ifs(currency == "HKD HK$", [0.7, 1.1], currency == "MOP MOP$", [0.65, 1.1], currency == "TWD NT$", [0.15, 0.3], currency == "JPY ¥", [0.03, 0.07], currency == "KRW ₩", [0.003, 0.008], currency == "SGD S$", [4.5, 6.5], currency == "MYR RM", [1.2, 2.1], currency == "THB ฿", [0.15, 0.3], currency == "PHP ₱", [0.08, 0.16], currency == "IDR Rp", [0.0003, 0.0006], currency == "VND ₫", [0.0002, 0.0004], currency == "LKR Rs", [0.015, 0.035], currency == "AED Dh", [1.5, 2.5], currency == "TRY ₺", [0.08, 0.35], currency == "GBP £", [7.5, 11.5], currency == "EUR €", [6.5, 9.5], currency == "PLN zł", [1.4, 2.5], currency == "CHF Fr", [7, 10.5], currency == "USD $", [6, 8], currency == "CAD C$", [4, 6.2], currency == "MXN Mex$", [0.28, 0.5], currency == "BRL R$", [0.9, 1.8], currency == "AUD A$", [3.6, 5.6], currency == "NZD NZ$", [3.3, 5.3], []),
  /* Note: empty(0) is true, so format() tells "empty" from "0" */
  [
    if(!hasCard, "Not linked to a SIM card", ""),
    if(empty(day), "Date is missing",
      if(dateBetween(dateStart(day), today(), "days") > 0, "Date is in the future", "")),
    if(kind == "", "Type is missing", ""),
    if(currency == "", "Currency is missing", ""),
    if(amountText == "", "Amount is missing (enter 0 for free)", ""),
    if(currency != "" and currency != "CNY ¥" and prop("Amount") > 0 and empty(rate), "Foreign currency without a rate", ""),
    /* An inverted rate (e.g. 23 instead of 0.043) makes the CNY amount wrong by orders of magnitude */
    if(currency == "" or currency == "CNY ¥" or empty(rate) or empty(range), "",
      if(rate < range.at(0) or rate > range.at(1), "Rate " + format(rate) + " is outside the usual range for " + currency + " (" + format(range.at(0)) + "–" + format(range.at(1)) + "); is it inverted?", "")),
    /* The last 4 digits in the title should match the linked card */
    if(cardDigits.length() < 4, "",
      if(!prop("Record").contains(cardDigits.substring(cardDigits.length() - 4)), "Title does not match the linked card's last 4 digits; wrong card?", "")),
    /* "Extends To" is required for initial purchases and renewals, not allowed for top-ups and other fees, and must be after the date */
    if((kind == "Initial purchase" or kind == "Renewal") and empty(extendsTo), "\"" + kind + "\" record is missing \"Extends To\"", ""),
    if(!empty(extendsTo) and (kind == "Extra top-up" or kind == "Other fee"), "\"" + kind + "\" does not extend validity; leave \"Extends To\" empty", ""),
    if(empty(extendsTo) or empty(day), "",
      if(dateBetween(dateStart(extendsTo), dateStart(day), "days") <= 0, "\"Extends To\" should be after the date", "")),
    /* Validity span: renewals at most "cycle + 30 days" (400 when irregular); initial purchases only catch year typos beyond 1830 days */
    if(empty(extendsTo) or empty(day) or !hasCard, "",
      lets(
        limit, if(kind == "Initial purchase", 1830, if(empty(cycleDays), 400, cycleDays + 30)),
        if(dateBetween(dateStart(extendsTo), dateStart(day), "days") > limit, "Validity span exceeds " + format(limit) + " days; check the year", ""))),
    if(prop("Amount") > 0 and empty(prop("Payment Account")), "Paid but no payment account", "")
  ].filter(current != "").join("; ")
)
```
